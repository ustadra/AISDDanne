# Procedencia de lo adaptado

Las piezas del kit AI_SDD que se adoptaron en este repo (agente `qa`, skills `objetivo`, `orquesta` y `nuevo-agente`, regla `ejecuciones.md`, hooks y git hooks) vienen de `https://github.com/vault-cowork/AI_SDD` (versión `v2026.10.25`, sellada en `.claude/kit-version.json`). El kit adapta ideas de [gzurl/agent-squad](https://github.com/gzurl/agent-squad) (MIT, commit `0e82cfc`): la verificación por objetivos en dos partes, los resultados pasada/fallada/no comprobable, las prioridades P1/P2/P3, el veredicto atado a un commit, el ritmo de una ronda de preguntas y una aprobación, y la regla de ejecuciones.

Lo propio de este repo (agentes `constructor-android` y `revisor-android`, skill `examen`, `knowledge/`, `plantilla/`, `tools/compilar.sh`) se escribió aquí a partir del temario y los ejercicios de clase.
